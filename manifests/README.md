# Manifests

Lightweight CSV manifests for PDF files stored outside Git, primarily in Google Drive.

Recommended files:

- `drive_inventory.csv`
- `approved_manifest.csv`
- `ocr_gain_manifest.csv`
- `user_provided_manifest.csv`

Each row should include the Drive path, local restore path, source URL, category, validation metrics, file size, and SHA256 hash.
